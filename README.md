### [Rozgar Saathi](https://github.com/xenion80/rozgar_saathi)

An academia–industry collaboration portal built for **Smart India Hackathon 2026 (Problem Statement SIH26044)** — focused on **skill mapping, internships, and placement**.

- 🔗 **Live Frontend:** [rozgar-saathi-f.onrender.com](https://rozgar-saathi-f.onrender.com)
- 🔗 **Backend API (Swagger):** [rozgar-saathi.onrender.com](https://rozgar-saathi.onrender.com)
- 🤖 Powered by a **Gemini AI coach** for personalised career advice and skill-building strategies.
- 📊 Features **explainable opportunity matching** — scores candidates based on skill coverage against role requirements.
- 👥 Role-based access for **Students, Recruiters, and Admins** with JWT authentication.
- 🧠 Includes skill assessments, skill gap analysis, and recruiter shortlisting pipelines.
- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, Zustand, Framer Motion.
- **Backend:** Java 25, Spring Boot 4, PostgreSQL, Cloudinary, JUnit 5 & Mockito.
